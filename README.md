# Техническое задание на разработку программного продукта
## «Калькулятор стоимости обеда в столовой»

---

## 1. Назначение программы

Программа предназначена для автоматического расчёта стоимости комплексного обеда в корпоративной столовой. Пользователь выбирает блюда из меню, указывает количество порций, время посещения и наличие скидочной карты. Программа рассчитывает итоговую стоимость с учётом скидок и наценок, а также может подобрать оптимальный набор блюд под заданный бюджет.

**Область применения:**  
- Корпоративные столовые  
- Учебные заведения  
- Кафе быстрого питания  
- Личное использование для планирования питания

---

## 2. Входные данные

| № | Параметр | Тип данных | Диапазон | Описание |
|---|----------|------------|----------|-----------|
| 1 | Выбор блюд | список | 1-10 позиций | Пользователь выбирает из предложенного меню |
| 2 | Количество порций | целое число | 1-5 | Для каждого выбранного блюда |
| 3 | Час посещения | целое число | 8-20 | Час (от 8:00 до 20:00) |
| 4 | Наличие скидочной карты | логический | да/нет | Есть ли у пользователя скидочная карта |
| 5 | Бюджет (для оптимизации) | число | любое положительное | Желаемая стоимость обеда |

## 3. Выходные данные

| № | Параметр | Формат | Описание |
|---|----------|--------|-----------|
| 1 | Базовая стоимость | число (2 знака) | Сумма цен всех блюд с учётом количества порций |
| 2 | Размер скидки | число (2 знака) | Сумма скидки в рублях (если применима) |
| 3 | Размер наценки | число (2 знака) | Сумма наценки в рублях (если час пик) |
| 4 | Итоговая стоимость | число (2 знака) | Базовая стоимость - скидка + наценка |
| 5 | Детализация заказа | текст | Перечень блюд с количеством и стоимостью |
| 6 | Лог-файл | текстовый файл | Запись каждого расчёта с датой и временем |
| 7 | Оптимальный набор | список блюд + цена | При использовании режима оптимизации |

## 4. Функциональные требования

### 4.1. Основные функции

| ID | Требование | Приоритет |
|----|------------|-----------|
| FR1 | Вывод меню с ценами на экран | Высокий |
| FR2 | Ввод выбора блюд с валидацией | Высокий |
| FR3 | Ввод количества порций (1-5) с валидацией | Высокий |
| FR4 | Расчёт базовой стоимости (цена × количество) | Высокий |
| FR5 | Ввод часа посещения (8-20) с валидацией | Высокий |
| FR6 | Ввод наличия скидочной карты | Высокий |
| FR7 | Расчёт итоговой стоимости с учётом скидок/наценок | Высокий |
| FR8 | Округление результата до 2 десятичных знаков | Средний |
| FR9 | Логирование каждого расчёта в файл с timestamp | Средний |
| FR10 | Режим оптимизации под заданный бюджет | Средний |
